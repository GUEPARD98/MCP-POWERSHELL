# 🔒 REQUISITOS DE SEGURIDAD
# =======================================

## 🔑 Autenticación SSH
# Método RECOMENDADO: Claves SSH (sin contraseña)
# 1. Generar par de claves: `ssh-keygen -t rsa -b 4096`
# 2. Copiar clave pública: `ssh-copy-id user@server`
# 3. Verificar permisos: chmod 600 ~/.ssh/id_rsa
# 4. Testear conexión: `ssh user@server`

# Método LEGACY: Usuario/contraseña (menos seguro)
# - Solo para entornos de desarrollo/testing
# - No recomendado para producción
# - Requiere herramientas adicionales (sshpass, plink)

## 🛡️ Configuración de Firewall
# Permitir conexiones SSH salientes (puerto 22)
# Windows Defender: crear regla para ssh.exe
# Linux iptables: permitir OUTPUT en puerto 22
# macOS: generalmente sin restricciones

## 🔐 Permisos de Archivos
# Claves SSH privadas: 600 (solo owner read/write)
# Archivos de configuración: 644 (owner rw, group/other r)
# Scripts ejecutables: 755 (owner rwx, group/other rx)

# =======================================
# 🔧 TROUBLESHOOTING COMÚN
# =======================================

## ❌ Error: "ssh command not found"
# Solución Windows: Habilitar OpenSSH Client en Windows Features
# Solución Linux: `apt install openssh-client`
# Solución macOS: ssh debería estar preinstalado

## ❌ Error: "Permission denied (publickey)"
# Solución: Verificar que la clave SSH está configurada correctamente
# Verificar: `ssh user@host` funciona manualmente
# Verificar permisos: chmod 600 ~/.ssh/id_rsa

## ❌ Error: "Node version not supported"
# Solución: Instalar Node.js 18+ desde nodejs.org
# Verificar: `node --version` debe mostrar 18.x.x o superior

## ❌ Error: "Claude Desktop no encuentra el servidor MCP"
# Solución: Verificar rutas absolutas en claude_desktop_config.json
# Verificar: El servidor se ejecuta sin errores con `npm start`
# Reiniciar: Claude Desktop después de cambiar configuración

## ❌ Error: "shell-escape module not found"
# Solución: Ejecutar `npm install` para instalar dependencias
# Verificar: package.json incluye shell-escape en dependencies
